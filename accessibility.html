Accessibility Statement

Last updated: 5 June 2026Accessibility support

Accessibility aim

Better Site aims to make bettersite.co.nz usable and accessible for visitors, including people using keyboards, screen readers, zoom, mobile devices, and other assistive technologies.

The site is designed to help small business owners understand the services, pricing, care plans, process, and contact options without unnecessary friction.

Current accessibility features

  • Skip link for jumping to the main page content.
  • Semantic HTML structure with headings, navigation, main content, forms, and footer regions.
  • Visible focus styles for keyboard navigation.
  • Responsive layout for desktop and mobile screens.
  • Labelled form fields on the contact and mockup request forms.
  • Decorative images marked appropriately where they do not add meaning.
  • Email contact available if a form is difficult to use.

Ongoing improvements

Accessibility is an ongoing effort. Some animated effects, browser differences, assistive technology combinations, older devices, or third-party services may not behave perfectly.

Better Site will review reported issues and make practical improvements where possible.

Report an accessibility issue

If you have trouble using the site, email contact@bettersite.co.nz.

Please include the page URL, what you were trying to do, the device or browser you were using, and any assistive technology involved if you are comfortable sharing that. Better Site will review the issue and try to provide the information or path you need in a practical alternative format where possible.
